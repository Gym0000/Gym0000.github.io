# Chinese name font

`yiming-name-serif.woff` contains only 高一鸣, using the Regular glyphs
from Adobe Source Han Serif SC. It is served locally for consistent rendering.

Official source:
https://github.com/adobe-fonts/source-han-serif

Font source:
https://raw.githubusercontent.com/adobe-fonts/source-han-serif/release/OTF/SimplifiedChinese/SourceHanSerifSC-Regular.otf

The font was subset and converted to WOFF without changing glyph outlines.
Its family and PostScript names were changed to Yiming Name Serif and
YimingNameSerif-Regular to respect the reserved font name.
